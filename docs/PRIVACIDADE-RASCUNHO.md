# Privacidade — rascunho técnico (não publicar como política final)

Na versão de teste do Volta do Lance, o vídeo e o áudio são capturados apenas com o app aberto e permissões concedidas. O recurso de reconhecimento de comandos usa processamento no dispositivo somente quando disponível. Os arquivos são mantidos no aparelho; o app não solicita acesso à internet e não envia gravações a servidores.

O armazenamento privado temporário é utilizado para fragmentos MP4. Os registros concluídos são salvos na pasta Movies/VoltaDoLance, acessíveis pela galeria do sistema. Apagar o app não apaga necessariamente os arquivos já exportados para a galeria.

Este texto cobre **somente a alpha**. Antes de adicionar faturamento, analytics ou cadastro, será necessária uma política pública revisada, incluindo todas as práticas reais de processamento e dados de pagamento.
